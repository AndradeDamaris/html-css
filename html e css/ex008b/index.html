Outras formatações

Code e pre

Code

Quando queremos escrever códigos o ideal é usar o <code> porque deixa as letras tudo com o mesmo espaçamento por exemplo
<link rel="icon" href="favicon.ico" type="image/x-icon">

Pre

Também da pra usar o código <pre> pra formatação ficar igual a eu escrevo aqui no HTML, por exemplo
<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Título da Página</title> </head> <body> </body> </html>

(sem formatação)

Citações simples e completas

Simples

Para fazer uma citação simples do tipo, segundo minha mãe: muito ajuda quem não atrapalha uso a tag <q> que é a simplificação de quotation

Completa

Para citações completas tipo: assim como disse o Sr. Darcy no livro de Jane Austen

Em vão tenho lutado. Nada consegui. Não posso mais. Sou incapaz de reprimir meus sentimentos. Permita-me dizer-lhe com que ardor a admiro e a amo
usamos a tag <blockquote>

Abreviações

Quando abreviamos algo dentro do site podemos colocar o significado dessa abreviação e assim que passar o mouse em cima da pra ver o significado por exemplo:
gosto muito dos meninos do Skz

Texto invertido KKKKK

Uma tag bem inútil na verdade, mas engraçada. Serve pra inverter a ordem das letras por exemplo
Socorram-me subi no ônibus em Marrocos
